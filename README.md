# Simple Calculator Project

A simple calculator project that handles basic arithmetic operations

## Features

This application includes the following four functions:

*   **Addition:** Computes the sum of two numbers.
*   **Subtraction:** Calculates the difference between two numbers.
*   **Multiplication:** Finds the product of two numbers.
*   **Division:** Divides one number by another (includes built-in validation to prevent division by zero).


## Getting Started

### Installation

1. Clone the repository:
```
   git clone <project-link>
   cd simple-calculator
```

3. Install dependencies (if applicable):
```
   # Example for Python
   pip install -r requirements.txt
```
